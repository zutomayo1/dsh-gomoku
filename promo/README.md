# 宣传片

`dsh-gomoku` 的宣传片：29.0 秒 / 1920×1080 / 30fps / 870 帧 / **带音轨**。

```
promo/
  promo.html    ← 舞台：一页确定性动画（window.__seek(t) 定帧渲染）
  audio.mjs     ← 音轨合成：纯 JS 写一条 120 BPM 的电子乐（WAV）
  shoot.mjs     ← 逐帧截图：headless Chrome + CDP（Node 内置 WebSocket，无 Playwright）
  probe.mjs     ← 几何/样式自检：打印相机矩阵与元素矩形，带页面异常捕获
  build.ps1     ← 一条命令：合成音轨 → 渲染 → 编码 → 混音 → 抽定妆照
  out/          ← 成片与定妆照（build.ps1 生成）
  frames/       ← 中间帧（构建产物，不入版本库）
```

## 为什么是"逐帧渲染"而不是录屏

片子里每个镜头都要精确可控：第几帧落子、第几帧连线画完、镜头第几帧推到棋盘、
**棋子正好落在第几个 16 分音符上**。录屏有掉帧和编码抖动，而且不可重跑——改一句
字幕就得重新录。

所以 `promo.html` 暴露纯函数 `window.__seek(t)`（t 单位秒），把所有动效按 t 算成内联
样式或 canvas 绘制：没有 CSS `transition`、没有 `requestAnimationFrame`、没有
`Math.random`、没有 `Date.now`。同一个 t 永远给出同一帧。

## 整片卡在 120 BPM 上

音轨是 120 BPM（拍 = 0.5s，16 分 = 0.125s），**画面的事件全部落在拍上**：

| 时间 | 事件 | 音乐 |
|---|---|---|
| 0.06–0.50 | 白光飞入 | riser 渐强 |
| **0.50** | 命中（第 1 拍） | 冲击 + 底鼓 |
| 1.00 / 1.50 / 2.00 | 标题 / 副标 / 横线 | 每拍一记底鼓 |
| 3.00 | 主界面飞入（切场） | 4-on-the-floor 起 |
| 7.50 | 对局开始 | 贝斯 + 16 分琶音进 |
| 7.50–13.9 | 37 手：前 24 手 16 分（0.125s/手）、中 10 手 8 分、末 3 手 4 分 | 珠子般的琶音 |
| 14.00–14.50 | 命中停顿（音乐抽空到 -38 dB） | 鼓组全停 |
| **14.50** | 五连 drop（第 29 拍） | 最强冲击 + 和弦刺 |
| 18.00 | 智能体工具场景（切场） | 低通过场 |
| 21.50 | 模式场景（切场） | 重新推进 |
| 24.50 | 收尾（切场） | 和弦刺 + 渐弱 |
| 29.00 | 结束 | 淡出 |

底鼓每拍给画面一个"冲击包络"：轻微的缩放（+0.6%）、一层蓝光、2–3px 震动。
**这就是"炸裂"的来源**——不是某个大特效，而是每秒两次的呼吸与画面同频。

## 音轨怎么来的

`node promo/audio.mjs` 用纯 JS 合成（不找现成音乐）：底鼓是正弦扫频 + 咔哒，踩镲是
差分高通噪声，贝斯是带包络低通的锯齿 + 软削波，琶音是锯齿/方波混合、左右交替摆位，
铺底是两个失谐锯齿；每次底鼓还会把中低频压下去一点（**侧链**），这是电子乐"呼吸感"
的来源。噪声用固定种子的 xorshift，所以重跑得到字节一致的音轨。

段落响度（`ffmpeg -af volumedetect` 实测，用来确认编曲真有起伏）：

```
intro    -15.9 dB        verse  -11.5 dB        game   -11.5 dB
gap      -38.1 dB  ← 抽空        drop   -10.9 dB  ← 最响
tools    -11.0 dB        outro  -11.5 dB
```

改 BPM 要同时改 `audio.mjs` 与 `promo.html` 里的常量。

## 画面里有什么"炫"

| 手段 | 实现 |
|---|---|
| **霓虹地格** | canvas 画 synthwave 透视地格：竖线向消失点汇聚、横线朝观众滚过来，随节拍变亮 |
| **粒子** | 两块 canvas：`#fxBack`（浮尘、开场白光与冲击波、五连全屏放射 + 44 条速度线）与棋盘内的 `#boardFx`（落子冲击环 + 火花 + 沿连线喷发）。棋盘那块用棋盘坐标系，自动跟着镜头变换 |
| **3D 镜头** | `#app` 挂 `perspective`，`#cam` 每帧算 `translate3d + scale + rotateZ/X/Y`；命中停顿时推到 1.92 倍，drop 时拉回 1.18 倍并把顶部让给大字 |
| **低频呼吸** | 每拍缩放脉冲 + 蓝光 + 震动（见上） |
| **切场** | 每次切场一个强脉冲 + 白闪 + 12px 震动 |
| **动能大字** | 98px 飞入 + 运动模糊收敛 + 色差（红/青两路 `mix-blend-mode:screen`） |
| **后期** | 上下 54px 黑边、扫描线、暗角 |
| **终端逐字打印** | 工具场景按字符预算打印，末尾带闪烁光标 |

## 内容

七段：开场 → 边聊边下 → 37 手对局 → 五连 → **智能体工具** → 三档模式 → 收尾
（仓库、安装命令、特性跑马灯、278 项自检）。

工具场景里那段盘面**不是编的**：取真实对局第 25 手之后、行 4–9 / 列 4–10 的裁切，
下一手就是真实谱里的白 `(9,6)`。延迟徽章上的 4.1 ms 也是实测的引擎耗时中位数：

```powershell
cd ../dsh-gomoku-host
node -e "import('./src/ai.js').then(async m => { const b=new Array(225).fill(0);
  b[7*15+7]=1;b[7*15+6]=2;b[8*15+7]=1;b[9*15+7]=2;b[6*15+7]=1;b[5*15+7]=2;b[8*15+6]=1;
  const a=[]; for(let i=0;i<200;i++){const t0=process.hrtime.bigint();m.chooseMove(b,1);a.push(Number(process.hrtime.bigint()-t0)/1e6);}
  a.sort((x,y)=>x-y); console.log('median', a[100].toFixed(2), 'ms'); })"
# -> median 4.05 ms
```

棋盘本身照抄 `dsh-gomoku-client` 的真实绘制参数（`STEP/PAD/STONE_R`、木纹四段渐变、
11 条木纹带、棋子六层叠加、星位、坐标字号）。

## 重建

```powershell
pwsh promo/build.ps1           # 全套（约 8 分钟）
pwsh promo/build.ps1 -Still    # 只出 7 张定妆照（20 秒，用来调构图）
pwsh promo/build.ps1 -Fps 60   # 60fps
node promo/audio.mjs           # 只重做音轨
```

需要 Chrome 或 Edge（`CHROME_PATH` 可覆盖）和 `ffmpeg`。

## 调试这套东西的四条经验

**一、`seek()` 半路抛错会让"半部片子"静止。** 所有元素都靠 `seek()` 每帧刷样式，只要中间
有任何一处 `.innerHTML = ...` 撞上 `null`，**它之后的每个场景整块不动**，而画面看上去只是
"少了几样东西"。踩过的那次是重写棋盘标记时漏掉 `#latency`，于是动能大字、五连标题、字幕、
屏幕震动全部停在前一帧。

两道闸：`promo.html` 加载时校验 `REQUIRED` 元素（缺了直接抛），`shoot.mjs` 监听
`Runtime.exceptionThrown` 并在**任何一帧抛错时中止整次渲染**，免得把坏帧编进成片。

**二、别在动画世界里用 `transform-style: preserve-3d`。** 一旦 `#world` 成为 3D 渲染上下文，
子元素 `z-index` 就失效，旋转过的窗口会盖住上层大字（「五连」因此整块消失过）。透视要挂在
各自需要的地方。

**三、`.layer` 的 `inset:0` 会把元素拉成整屏高。** 一个 `position:absolute; bottom:NNpx`
的元素，如果还带着 `.layer` 的 `top:0`，高度就变成"整屏减 NN"，里面的内容被顶到画面最上面
（字幕和跑马灯都踩过）。**必须显式写 `top:auto`。**

**四、终端/代码块记得 `white-space:pre`**，否则多个空格会被折叠，盘面裁切就对齐不了。

定位这些问题时，`probe.mjs`（相机矩阵 + 各元素屏幕矩形 + `display/opacity/font-size`）
比盯着图猜快得多。

## 已知取舍

- **不是真机录屏。** 主界面是按 DSH 的布局手搭的 mock（深色）。片子的价值在于把"边聊边下"
  "引擎秒回""模型可代打"讲清楚，而不是像素级复刻 DSH 的外壳。
- **音轨是合成器味的电子乐**，不是成品音乐。要换成真曲子：把音轨放进 `promo/`，改
  `build.ps1` 里那一行 `-i $wav` 即可（画面的事件已经卡在 120 BPM 上，换歌要么同速，
  要么同步改 BPM 常量）。
- 模式卡片用了 emoji（⚡🧠✋）：四十秒的片子里它比矢量图标更快读懂。
